JSON2Model, portable Windows application
========================================

Double-click JSON2Model.exe to start.

No installation, Python, Docker, Node.js, account, or internet connection is
required. JSON conversion happens entirely inside the application on this
computer, and nothing you paste is sent anywhere.

Keep the complete Application folder together. The DLL and resource files next
to JSON2Model.exe are part of the application.

Windows may show a SmartScreen warning because this independently distributed
application is not code signed. If you trust where the folder came from, choose
"More info" and then "Run anyway".

Supported output:
  Dart null safe models with fromJson and toJson
  Strict TypeScript interfaces and type aliases
  Python Pydantic 2 models with aliases
